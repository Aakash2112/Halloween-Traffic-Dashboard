# Halloween Traffic Analysis 🎃

## Overview
This project analyzes historical Halloween traffic data (2008-2016) for East Walnut Hills, Cincinnati. The goal is to help residents identify the best time to go trick-or-treating based on crowd intensity, time blocks, and visitor trends using graphical methods.

## Tools Used
- Tableau (Data Visualization)
- Excel (Data Source)

## Dashboard Highlights
- Visitor Arrival Distribution by Day & Time
- Visitor Distribution During vs After Official Hours
- Stragglers Trend Over the Years
- Footfall Comparison Across Years
- Total Visitors & Crowd Flow Intensity Over Time

## Recommendation
Residents are advised to start trick-or-treating as early as possible (6:00 PM) to avoid peak crowd hours and minimize waiting time.
